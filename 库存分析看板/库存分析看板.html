计算口径与指标说明▼

核心假设（务必先读）

  • 估算销量 = 期初库存 − 期末库存（SKU 层取 max(0, 差值) 用于售罄率；整体 / 品类用汇总净减少，可能为负，表示净入库）。
  • 净减少同时包含销售、退货、补货、调拨、报废等所有出入库影响，有补货时会低估销量与周转、售罄指标。
  • 两个时点之间只有首尾快照，无法还原中间过程；周转指标是「期间平均库存」近似，不是财务明细账口径。

售罄率（SKU / 品类 / 整体）

  • 售罄率 = 净减少量 ÷ 期初库存
  • SKU：期初库存为 0 时不计算（显示 —）；品类 / 整体：Σ净减少 ÷ Σ期初库存，新增 SKU 会拉低整体售罄率。
  • 售罄率为 100% 表示期初库存全部减少，不等于全部卖出（可能含报废、调拨）。

库存周转率与周转天数

  • 平均库存 = (期初库存 + 期末库存) ÷ 2
  • 周转率 = 净减少量 ÷ 平均库存（净减少 ≤ 0 时不计算）
  • 周转天数 = 期间天数 ÷ 周转率 = 平均库存 × 期间天数 ÷ 净减少量，期间天数 = 期末日期 − 期初日期。

动销率

  • 动销率 = 净减少 > 0 的 SKU 数 ÷ 期初库存 > 0 的 SKU 数
  • 净减少 ≤ 0（含无变化与净增加）均视为未动销。

滞销与断货风险

  • 库存天数 = 期末库存 × 期间天数 ÷ 净减少量：按期间净减少速度，现有库存还能卖多少天。
  • 滞销：期末库存 > 0，且（净减少 ≤ 0，或库存天数 > 滞销阈值，默认 90 天）。
  • 断货风险：期初有库存但期末 ≤ 0；或仍有期末库存但库存天数 < 断货阈值（默认 14 天）。
  • 阈值可在明细筛选区调整，修改后风险分类与 KPI 同步刷新。

库存金额与结构

  • 单价优先取期末文件对应列，缺失时回退期初文件；表头含「成本 / 进价 / 采购价」识别为成本价，其余识别为零售价，可在上传卡手动改。
  • 库存金额 = 库存数量 × 单价；两个时点使用同一单价，金额变化只反映数量变化。
  • 未识别到单价列时不展示金额类指标，结构图按库存数量展示；部分 SKU 缺单价时金额为已覆盖部分，KPI 会提示覆盖率。
  • 金额占比 = 某品类期末金额 ÷ 全部品类期末金额。

商品匹配与字段识别

  • 优先按 SKU / 货号 / 条码匹配；无该类字段时按「品名 + 规格」匹配。同一文件内重复商品自动累加数量。
  • 自动识别工作表与表头行（扫描前 20 行），列名支持常见别名模糊匹配；识别不准可在上传卡手动指定。
  • 品名自动省略「BLACK PAW / 黑爪」字样。
