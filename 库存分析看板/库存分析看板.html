计算口径与指标说明▼

核心假设（务必先读）

  • 估算销量 = 期初库存 − 期末库存（SKU 层取 max(0, 差值) 用于售罄率；整体 / 品类用汇总净减少，可能为负，表示净入库）。
  • 净减少同时包含销售、退货、补货、调拨、报废等所有出入库影响，有补货时会低估销量与周转、售罄指标。
  • 两个时点之间只有首尾快照，无法还原中间过程；周转指标是「期间平均库存」近似，不是财务明细账口径。

售罄率（SKU / 品类 / 整体）

  • 售罄率 = 净减少量 ÷ 期初库存
  • SKU：期初库存为 0 时不计算（显示 —）；品类 / 整体：Σ净减少 ÷ Σ期初库存，新增 SKU 会拉低整体售罄率。
  • 售罄率为 100% 表示期初库存全部减少，不等于全部卖出（可能含报废、调拨）。

库存周转率与周转天数

  • 平均库存 = (期初库存 + 期末库存) ÷ 2
  • 周转率 = 净减少量 ÷ 平均库存（净减少 ≤ 0 时不计算）
  • 周转天数 = 期间天数 ÷ 周转率 = 平均库存 × 期间天数 ÷ 净减少量，期间天数 = 期末日期 − 期初日期。

动销率

  • 动销率 = 净减少 > 0 的 SKU 数 ÷ 期初库存 > 0 的 SKU 数
  • 净减少 ≤ 0（含无变化与净增加）均视为未动销。

滞销与断货风险

  • 库存天数 = 期末库存 × 期间天数 ÷ 净减少量：按期间净减少速度，现有库存还能卖多少天。
  • 滞销：期末库存 > 0，且（净减少 ≤ 0，或库存天数 > 滞销阈值，默认 90 天）。
  • 断货风险：期初有库存但期末 ≤ 0；或仍有期末库存但库存天数 < 断货阈值（默认 14 天）。
  • 阈值可在明细筛选区调整，修改后风险分类与 KPI 同步刷新。

库存金额与结构

  • 库存金额 = 库存数量 × 单价；默认按零售价口径计算，非成本。期初、期末使用同一单价，金额变化只反映数量变化。
  • 单价来源优先级：① 库存文件自带的有效单价（> 0，期末优先、缺失回退期初）；② 库存文件无有效价格时，自动回填商品信息的价格字段（默认优先零售价 / 吊牌价 / 售价，其次单价，最后才是成本 / 进价）。
  • 商品信息价格列会做清洗：去除「¥ / ￥ / 元 / RMB」、千分位、空格与全角数字；空值、#N/A 等无法解析的计为「价格缺失」，在结果页提示数量，其金额不计入合计。
  • 商品信息同时存在零售价与成本价时默认取零售价，可在上传卡手动切换；若切到成本价，页面与导出会标注为成本口径。
  • 未识别到任何有效价格时不展示金额类指标，结构图按库存数量展示；部分 SKU 缺价格时金额为已覆盖部分，KPI 与明细脚注会提示覆盖率和缺失数量。
  • 金额占比 = 某品类期末金额 ÷ 全部品类期末金额；清空 SKU 的期初金额计入「清空金额（售罄金额）」。

商品信息（商品主数据）

  • 商品信息为可选文件，用于限定分析范围并补充运营字段；上传后在当前页面会话内缓存，切换模块或重新计算无需重传，刷新页面后需重新上传。
  • 匹配顺序：库存明细的货号 / SKU 先匹配商品信息的主键列（货号 / SKU / 商品编码），未命中再匹配条码，最后按「品名 + 规格」兜底；主键列可手动指定。
  • 启用商品信息后，仅分析能匹配上的商品；未匹配数量会在结果页顶部提示，并在导出 Excel 的「未匹配商品」工作表中列出，不会被静默丢弃。
  • 商品信息的主键、品名、规格、品类会覆盖库存明细对应字段，其余字段（条码、零售价、生产备注等）追加为明细列；全部字段均可作为多选筛选条件，与滞销 / 断货阈值、搜索等筛选为 AND 组合。
  • 不区分大小写与首尾空格；主数据内主键重复时保留首条并在上传卡提示。

商品匹配与字段识别

  • 库存明细内部优先按 SKU / 货号 / 条码匹配；无该类字段时按「品名 + 规格」匹配。同一文件内重复商品自动累加数量。
  • 自动识别工作表与表头行（扫描前 20 行），列名支持常见别名模糊匹配；识别不准可在上传卡手动指定。
  • 品名自动省略「BLACK PAW / 黑爪」字样。

上传期初与期末库存明细后开始分析

系统会自动识别工作表、表头行和常见列名（货号 / SKU / 条码、品名、规格、品类、库存数量、单价）。 识别结果会先展示，确认无误后再点击「确认并计算」。

可选上传「商品信息」作为主数据：上传后仅分析能按货号 / 条码 / 品名+规格匹配上的商品， 未匹配数量会在结果页提示；商品信息的全部字段可作为多选筛选条件，并随明细一起导出 Excel。
