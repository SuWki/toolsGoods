# toolsGoods

香水商品运营平台仓库，当前围绕四件事做商品决策：

- 防止好卖商品断货
- 识别临期和过期风险批次
- 找出长期不动销的滞销商品
- 给出门店之间的调拨建议

## 当前进度

第二版已经开始接真实业务文件：

- 支持模板明细表导入
- 支持 `90天销售.csv` 这类订单商品流水自动聚合
- 支持 Excel / CSV 导入
- 支持通用字段映射

## 目前最适合的导入方式

1. 一张标准明细表：一行代表一个 `SKU + 门店 + 批次`
2. 一张 90 天销售流水表：系统会自动聚合成 `SKU + 门店` 销售结果

## SKU 九宫格分析

九宫格以 **销售系数 × 库存系数** 为框架，根据商品消化周期自动将各 SKU 分配到对应格子。

### 坐标定义

| 轴 | 含义 | 数值 | 说明 |
|---|---|---|---|
| 横轴（X） | 销售系数 | 1 / 2 / 3 | 1 = 销售数量特别高，3 = 销售数量特别低 |
| 纵轴（Y） | 库存系数 | 1 / 2 / 3 | 1 = 库存数量特别少，3 = 库存数量特别多 |

### 消化周期分类规则

横轴 + 纵轴的数值之和对应商品的消化周期（即按当前销售速度卖完库存所需的天数）：

| X + Y | 消化周期 | 含义 |
|---|---|---|
| 2 | ≤ 90 天 | 快消化，需重点保供 |
| 3 | ≤ 180 天 | 正常流转 |
| 4 | ≤ 360 天 | 中等偏慢 |
| 5 | ≤ 720 天 | 消化较慢，需关注 |
| 6 | > 720 天 | 严重积压，需去库存 |

### 九宫格各格子备注

```
              X=1(高销售)     X=2(中销售)      X=3(低销售)
Y=1(低库存)    原价/补货       原价/关注        原价/不补
Y=2(中库存)    原价/关注       原价/不补        压力/消化
Y=3(高库存)    原价/不补       浮动/消化        折价/去库存
```

### 分类算法

1. **计算消化周期**：`消化周期 = (库存数量 / 销售数量) × 统计周期天数`
2. **确定系数之和**：根据消化周期按上表映射到 X+Y 的值（2~6）
3. **分配销售系数 X**：在同一消化周期组内，按销售数量降序排名，销售越高的商品 X 越小（趋近 1）
4. **推算库存系数 Y**：`Y = (X + Y) - X`

### 每周更新

用户每周更新数据源后，系统会根据最新的销售和库存数量重新计算每个商品的消化周期，并自动更新九宫格中的位置。可通过 KPI 筛选按钮快速查看各消化周期分类下的商品。
